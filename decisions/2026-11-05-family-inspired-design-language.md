# Design language inspired by the Family app, adapted for desktop

## Problem
JusDesk needed a visual language for the assignment.

## Decision
Take Family's (iOS crypto wallet) principles: black-and-white base, big hero numbers, pill buttons, soft grey rows, calm confirmation before final actions. Adapt for a dense desktop tool: smaller type, status colours, tighter spacing.

## Why
Not stated. Nitish chose Family as the reference.

## Evidence
Family screens on Mobbin ("Sending tokens" flow).   Confidence: Medium

## Rejected options
- Copying Family's mobile screens directly → a phone layout doesn't fit a dense desktop workspace.

## Guardrails for the next designer
- Buttons, badges and tabs stay fully rounded (pills).
- Lead each screen with one hero number where it helps.
- Refunds and declines show a summary before the final click.

## Revisit when
Juspay feedback asks for a different feel.
